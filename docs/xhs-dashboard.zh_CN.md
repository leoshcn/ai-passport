# 小红书创作者仪表盘

这份手册从关机的设备讲起。内容包括电脑上的服务、第一次配网、确认配对码、平时看数，以及设置页。

设备显示你有权使用的小红书创作者账号的粉丝数据。登录留在电脑上。设备保存家里的 Wi-Fi 密码，以及一只只用来向电脑要数字的令牌。网页和日志里不出现登录 Cookie、Wi-Fi 密码或这只令牌。

## 你需要准备

- 已经写入这份固件的设备。
- 一台能连 Wi-Fi 的手机。
- 一台电脑，和设备将要使用的家里网络在同一个局域网。Debian 和 Windows 都可以。
- 这台电脑上的 Docker，以及 Python 3。
- 一个你能登录的小红书创作者账号。

控制台只放在家里的网络里。不要把它发布到公网。

电脑上有两件事，都要一直开着：

- 发现进程跑在电脑自己上面。它听见设备，并把配对码交给控制台。只开 Docker 听不见这路广播。
- 控制台和设备接口用 Docker 启动。控制台是 TCP `8790`。设备接口是 TCP `8787`。发现进程听 UDP `8788`。

在电脑防火墙里，对家里的网络放行这三个端口。

## 打开设备

电源键和三个功能键是分开的。

- 按住电源键大约半秒，设备开机。
- 按住大约两秒，设备关机。

三个功能键是上、下、确定。点一下是短按。下面说的长按，是按住确定键大约半秒。

大约 30 秒没有按键，背光会变暗。按任何一个功能键，屏幕会重新变亮。右上角的百分比是电量。电量计没有读数时，这里是空的。

## 启动电脑上的服务

在要给设备提供数据的那台电脑上，进入仓库根目录。

Debian：

```bash
python3 backend/xhs_discover.py &
discover_pid=$!
trap 'kill $discover_pid' EXIT
docker compose up --build
```

Windows：

```text
powershell -File backend/start-xhs.ps1
```

让这个窗口一直开着。同一局域网里的另一台电脑打开 `http://<服务器局域网 IP>:8790`。在服务器自己上面，也可以打开 `http://127.0.0.1:8790`。

页面只有一种状态：未登录、已登录或已失效。

## 登录创作者账号

1. 点「扫码登录」。
2. 页面上出现创作者平台自己的二维码。在手机上确认。
3. 只有电脑读到账号数字之后，状态才会变成已登录。Cookie 框不会自动填上。

扫码失败时，打开「Cookie 备用」，把已经登录的浏览器里的 Cookie 粘贴进去再提交。检查方式相同。

要换账号时点「退出登录」。配对和设备令牌还在。设备大约一分钟内会跟上新账号。新数字到来之前，屏幕继续显示上一份。

状态变成已失效，表示保存的登录已经不能用。重新扫码，或粘贴一份可用的 Cookie。不需要重新配网。

## 把设备连上家里的 Wi-Fi

第一次使用时，以及之后在设置里重新配网时，设备会打开名为 `Passport-Setup` 的热点。屏幕上写着这个名字和地址 `192.168.4.1`。热点没有密码。

在手机上：

1. 连接 `Passport-Setup`。连上之后，手机会离开家里的 Wi-Fi。
2. 打开 `http://192.168.4.1`。如果没有自动弹出页面，就手动输入这个地址。
3. 填写家里的 Wi-Fi 名称和密码。
4. 「后端地址」留空。
5. 点连接。

设备显示「正在连接」。手机上的页面会自己刷新。

- 手机显示已经连上家里的 Wi-Fi 时，断开 `Passport-Setup`，重新连回家里的 Wi-Fi，然后看设备屏幕上的配对码。热点大约 15 秒后关闭。
- 手机显示没连上时，检查名称和密码后再试。错误密码不会被保存。设备回到热点画面。

只有这台电脑收不到广播时，才填写后端地址，格式是 `http://<服务器局域网 IP>:8787`。设备会直接问这个地址，不再广播。配对码仍然要在这台电脑的控制台上确认一次。

## 确认配对码

设备显示四位配对码。

控制台的「设备配对」下面，几秒内会出现带有同一组码的确认按钮。已经打开的页面会自己更新。点一次这个按钮。

电脑随后把令牌交给这台设备。以后再确认另一组码，会换掉原来的令牌，所以一台控制台只配一台设备。

按钮一直不出现时：

- 发现进程没有在控制台那台电脑上运行。用上面的命令，在那台电脑上、Docker 外面启动它。
- 手机还连着 `Passport-Setup`，设备还没有回到家里的网络。
- 填写的后端地址没有指向这台控制台。除非你就是要走直接填地址的办法，否则把这一栏留空。

## 看仪表盘

配对完成之后，屏幕上有：

- 账号名字和头像。第一次成功更新之前，名字是「尚未更新」。
- 粉丝。
- 获赞与收藏。
- 近 7 日净涨粉。增加和减少用不同颜色。第一次成功之前，这三项是横线。
- 最近一次更新的时间，用中国标准时间（UTC+8）。

在仪表盘上短按确定，会立刻再要一次数字。

自动更新默认打开，默认每天一次。设备大约每分钟看一次电脑上的账号有没有换。账号没变时，仍然按每小时或每天的周期更新。

后来某一次拉取失败时，上一份数字还在，最下面一行显示「更新失败」。

## 改设置

按住确定键大约半秒。设置里有四行。上、下键移动选中行。确定键进入这一行。

| 这一行 | 确定键做什么 |
| --- | --- |
| 自动更新 | 上、下键在「开」和「关」之间切换。再按确定保存。默认是开。 |
| 更新频率 | 上、下键在「每小时」和「每天」之间切换。再按确定保存。默认是每天。 |
| 立即刷新 | 按一次确定回到仪表盘。已经配网时立刻拉取。 |
| 重新配网 | 按一次确定，这一行变成「确认」。再按一次确定。 |

设置开着的时候，长按确定会保存并回到当前主画面。屏幕底部也会提示当前该怎么按。

重新配网会清掉保存的家里 Wi-Fi、后端地址和设备令牌。设备上的上一份数字还留着。热点 `Passport-Setup` 重新打开，再用手机配一次网，并再确认一次配对码。

## 出现失败画面时

有一个画面写着「配置失败，请重新刷新固件。」它有两种原因。

- 一开机就出现，还没有热点画面。设备打不开自己的存储。配网修不好。请重新刷新固件。
- 配对之后、任何数字出现之前才出现。第一次拉取失败了。在控制台登录，或者创作者平台暂时连不上时再等一会儿。设备大约每分钟重试一次。拉取成功后会回到仪表盘。这块画面显示着的时候，长按确定可以进入设置。

## 关掉电脑上的服务

在 Debian 上，关掉 Compose 那个窗口，也会停掉上面那条命令启动的发现进程。在 Windows 上，关掉启动脚本也会一起停掉。设备留着上一份数字，等你再次启动电脑上的服务后再继续更新。
