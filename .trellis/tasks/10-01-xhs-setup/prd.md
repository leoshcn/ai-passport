# 工程化部署与设备配网

## Goal

普通使用者可以装好小红书创作者仪表盘：在电脑上启动后端并扫码登录，设备第一次开机时用自己的热点完成配网，然后在局域网里被这台电脑发现并确认配对。不需要改固件源码、重新编译，或从浏览器开发者工具复制 Cookie。

## Background

- 后端现在是本机 Python，监听 `0.0.0.0:8787`。设备用 `X-Device-Token` 调用 `GET /api/v1/stats` 和 `GET /api/v1/avatar`。Cookie 在 `backend/xhs.cookie`，令牌在 `backend/device.token`，两者已忽略，响应不返回 Cookie（`backend/xhs_server.py`，`backend/README.md`）。
- 现有程序不代填密码、不处理验证码、不伪造平台签名。Cookie 只能来自使用者自己有权使用的创作者账号（`backend/xhs_fetch.py`）。
- Wi-Fi、后端地址和设备令牌目前写在 `main/xhs_config.h` 并编译进固件。必填项为空时停在失败页（`main/xhs_logic.h` 的 `xhs_config_usable`，`main/main.c`）。该头文件里已有真实联网参数，不能提交。
- 设备只有站点模式（`main/xhs_net.c`）。NVS 命名空间 `xhsdash` 只保存更新设置和上次数据（`main/xhs_store.c`）。
- 硬件是 ESP32-C3、8 MB Flash、无 PSRAM，屏幕 240×320，按键是上、下、确定。短时配网使用 APSTA，成功后再保存并关闭热点（`docs/reference/phoenixzhc/softap-provisioning-and-resource-budget.md`）。
- Docker Desktop for Windows 没有文档说明容器能收到物理局域网的 UDP 广播。已记录在 `research/lan-discovery-docker-desktop.md`。TCP 发布端口 `8787` 是设备访问 API 的可用路径。

## Requirements

1. 后端用 Docker Compose 发布设备 API。人用的控制台只绑定在本机，局域网里的其他设备打不开登录页和确认按钮。
2. 控制台的登录打开展作者平台自己的扫码页，由程序控制的浏览器会话读取扫码完成后的 Cookie，写入数据卷。页面只显示未登录、已登录或已失效。失效后可以重新登录，不必重建容器。扫码失败时可以粘贴 Cookie，粘贴后走同一套状态显示。
3. 不代填密码、不处理验证码、不伪造平台签名。页面、日志和设备响应都不出现 Cookie、Wi-Fi 密码或设备令牌。
4. 没有可用配网记录时，设备打开热点。热点页面收集家里的 Wi-Fi，并可选填后端地址。设备确认连上家里的 Wi-Fi 之后才写入 NVS，然后关闭热点。错误密码不写成成功配置；如果已有可用配置，失败时保留旧配置。
5. 未手填后端地址时，设备在连上 Wi-Fi 后广播配对请求，屏幕显示短配对码。Windows 上由宿主机进程接收广播并交给本机控制台。控制台列出相同配对码，使用者点一次确认。后端生成令牌，只交给这台设备保存。
6. 广播到不了时，使用热点页面里填写的后端地址，仍然要在控制台点一次确认后才保存令牌。
7. 设备设置中可以重新配网。确认后清除 Wi-Fi、后端地址和令牌，重新打开热点。已保存的创作者数据保留。
8. 固件源码和提交的配置模板不包含真实 Wi-Fi 密码、后端地址或设备令牌。
9. 仪表盘的数据字段、更新周期和现有按键设置保持不变。

## Acceptance Criteria

- [ ] 在 Windows 上用一个启动命令同时拉起控制台、设备 API 和广播接收进程。
- [ ] 另一台局域网设备访问控制台地址时连不上。本机能打开控制台。
- [ ] 未登录显示未登录。官方扫码成功后变为已登录，页面不出现 Cookie 全文。
- [ ] 会话失效时显示已失效。重新扫码或粘贴可用 Cookie 后恢复已登录。容器重启后已保存的登录态仍在。
- [ ] 无配网记录的设备出现热点。提交正确 Wi-Fi 后，设备获得地址，热点随后关闭。
- [ ] 提交错误密码时，设备留在可重试的配网状态，NVS 中没有这条失败密码。
- [ ] 启动命令正在运行时，设备屏幕上的配对码出现在控制台。点一次确认后，设备不再依赖编译进固件的地址，并能用令牌取到统计数据。
- [ ] 不启动广播接收、只在热点页面填写后端地址时，仍需控制台确认后设备才保存令牌。
- [ ] 在设备上确认重新配网后，热点重新出现，旧 Wi-Fi 密码和令牌不再保留，上次成功的统计数据还在。
- [ ] 日志、页面和固件源码中不出现 Cookie、Wi-Fi 密码或设备令牌。

## Out of scope

- 代填账号密码、绕过验证码，或伪造小红书签名。
- 把控制台或后端暴露到公网。
- 改仪表盘的数据字段、更新周期，或自动更新和周期这两个设置项。
- 用蓝牙配网小程序作为交付路径。
- 同时配对多台设备。新的确认会替换原来的设备令牌。
