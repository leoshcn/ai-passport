# 部署与配网设计

## Boundaries

| 部分 | 职责 | 不负责 |
| --- | --- | --- |
| 设备固件 `main/xhs_*` | 热点、配网页、NVS、广播或直连、仪表盘 | 登录小红书、保存 Cookie |
| 容器内 API | 统计和头像、配对状态、令牌发放 | 接收局域网 UDP 广播 |
| 本机控制台 | 扫码登录、粘贴 Cookie、确认配对码 | 被局域网其他机器访问 |
| Windows 发现进程 | 在物理网卡上收广播，把结果交给本机控制台，并把回复单播回设备 | 跑在容器里 |

人用的页面和设备 API 分开绑定。控制台发布在 `127.0.0.1:8790`。设备 API 发布在 `0.0.0.0:8787`。发现进程只访问 `127.0.0.1`。

## Operator flow

1. 启动脚本拉起发现进程和 `docker compose up`。
2. 浏览器打开 `http://127.0.0.1:8790`。未登录时点登录，页面显示创作者平台扫码图。程序用容器内浏览器打开官方登录页，只在 `fetch_stats` 能成功时把 Cookie 写入数据卷并关掉浏览器。
3. 无配网记录的设备开启开放热点 `Passport-Setup`，配网页在设备网关。页面包含 Wi-Fi 名称、密码，以及可留空的后端地址 `http://<电脑局域网 IPv4>:8787`。
4. 设备用 APSTA 试连。只有站点拿到 IP 才把 Wi-Fi 写入 NVS，然后关闭热点和配网 HTTP。失败则继续开着热点，并保留上一份成功配置。
5. 后端地址为空时，设备每数秒向子网广播一个短配对码，屏幕同时显示该码。发现进程把码交给控制台。使用者核对后点确认。
6. 填了后端地址时，设备改为向该地址轮询配对状态，不再依赖广播。确认动作相同。
7. 确认后 API 生成设备令牌。令牌只通过发给该设备的回复或轮询结果交付一次，设备写入 NVS。之后统计请求仍使用现有的 `X-Device-Token` 头。
8. 设置页增加「重新配网」。确定后清除 Wi-Fi、后端地址和令牌，保留 `xhsdash` 里的统计数据，再回到第 3 步。

## Contracts

配对码是 4 个不含易混字符的大写字母或数字，显示在设备和非确认前的控制台列表里。

设备广播和直连轮询都带配对码，不带 Wi-Fi 密码。发现进程回复的地址必须是收到广播的那块物理网卡的 IPv4，不能是 `172.x`、WSL 地址或 `host.docker.internal`。

控制台状态只有 `logged_out`、`logged_in`、`expired`。任何响应体都不含 Cookie 或令牌。日志只记状态名、HTTP 状态和配对码是否匹配，不记密钥材料。

NVS 在现有 `xhsdash` 命名空间增加 Wi-Fi 名称、密码、后端地址和设备令牌。`xhs_store_init` 在 NVS 版本异常时仍返回错误，不擦除分区。

`main/xhs_config.h` 改为空模板：空 SSID、空密码、空地址、空令牌。空配置表示进入配网，不再表示停在失败页。已填好的那份头文件不能进入提交。

配网页限制正文长度、字段长度和接收超时。Wi-Fi 名称不超过 32 字节，密码不超过 64 字节，地址仍由 `xhs_config_usable` 的规则检查。热点同时只接受少量客户端。配网 HTTP、DNS 和 AP 在进入仪表盘前停干净。

登录浏览器包在可替换接口后面。测试注入假的扫码结果，不启动 Chromium。

## Compatibility

设备 API 的统计和头像路径、请求头和 JSON 字段保持不变。旧的「编译进固件的地址和令牌」不再作为启动条件。已经写在当前工作区 `main/xhs_config.h` 里的参数不会被迁移；配对成功后的 NVS 才是新来源。

Docker Desktop 若被设成只把端口绑在 localhost，设备会连不上 `8787`。Compose 必须把设备 API 绑到 `0.0.0.0`。Windows 防火墙需要允许发现进程和 `com.docker.backend.exe` 的入站局域网访问。

## Trade-offs

- 发现进程放在 Windows 宿主机，是因为容器收不到局域网广播。多一个进程，换来不用在正常路径输入 IP。
- 控制台和 API 分端口，避免为了让设备访问统计接口而把登录页暴露到局域网。
- 一次只保留一个设备令牌。再次确认会使旧设备失效。
- 开放热点只在配网期间存在。配网用的短时风险，换的是手机不必再输入热点密码。

## Rollback

数据卷和 NVS 分开。删掉容器不清除设备配网；清除设备配网不删除电脑上的 Cookie。若要退回编译期配置，恢复让 `xhs_config_usable` 决定失败页，并停止启动热点。不要用擦除整片 Flash 来回滚。
