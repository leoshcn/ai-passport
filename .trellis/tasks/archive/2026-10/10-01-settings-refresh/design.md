# 立即刷新设计

## Boundaries

| 层 | 职责 |
| --- | --- |
| `xhs_logic` | 新设置项的光标移动，以及导航态一次确定：切到仪表盘，并在 `config_ok` 时置 `request_fetch`。不访问网络、NVS 或 LVGL。 |
| `xhs_ui` | 画出四行。新行右侧留空。压缩行高，使「长按确认键返回」仍在 320 高的屏幕里。 |
| `main.c` | 沿用现有 `request_fetch` 分支调用 `xhs_net_request_fetch()`，再 `present()`。只更新文件头里的按键说明。 |
| `xhs_net` / `xhs_store` | 不改。成功和失败仍走原来的结果处理。 |

## Flow

`xhs_item_t` 顺序为：自动更新、更新频率、立即刷新、重新配网。`XHS_ITEM_COUNT` 仍是上下循环的模。

导航态按确定时：

- 选中立即刷新：`view` 改为仪表盘，`mode` 保持导航。`config_ok` 为真才把 `request_fetch` 置真。`save_settings` 和 `request_reprovision` 保持假。
- 选中其他项：仍进入调整态。

立即刷新没有调整态。上下键在导航态只移动光标。调整态里若选中的是这一行，上下键不改自动更新或频率，确定键执行与导航态相同的离开动作。

长按确定仍先于该项处理：离开设置、回到当前主画面，并按原逻辑保存自动更新和频率。不因长按而拉取。

拉取进行中仪表盘继续显示上次数据。成功后的写回和失败页规则不变。设置页不再因为这次操作挡住结果，因为画面已经离开设置。

## Layout

四行卡片高 46、间距 6，从 y=56 起。末行在 y=258 结束。提示语留在 y=268。卡片宽仍为 208，x=16。行内文字相对 46 高的卡片垂直居中。

## Trade-offs

一次确定会立刻离开设置。这一项不改配置，误触只是多一次与数据页短按相同的拉取。重新配网仍要第二次确定。

未配网也回到仪表盘，而不是留在设置或跳进热点。数据页是用户指定的落点；没有可用配置时，现有门闩本来就不会发请求。长按确定再长按一次，仍能回到热点或配对画面。

不增加「正在更新」文案。数据页短按确定也是静默等待，两处保持同一表现。

## Rollback

删掉新枚举值和对应分支后，三项菜单与现有测试可以恢复。不要在同一次修改里改网络任务或待机背光。
