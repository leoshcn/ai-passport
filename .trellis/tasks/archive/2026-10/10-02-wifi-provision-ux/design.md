# 配网页设计

## Boundaries

| 部分 | 职责 | 不负责 |
| --- | --- | --- |
| `xhs_logic` | 合并扫描结果；解析 `ssid_manual` | 调用 `esp_wifi_scan_*`，拼 HTML |
| `xhs_net` 的网络任务 | 启动扫描、把驱动结果收进缓存、处理重新扫描 | 在 HTTP 处理函数里扫描 |
| `xhs_net` 的 HTTP | 读缓存并分块输出页面；接收有界表单 | 决定保存凭据的时机 |
| 现有 `xhs_prov_submit` | 连接成功后才写 NVS | 新增第四个持久化字段 |

## Data flow

1. `provision_start` 成功后，网络任务调用一次 `esp_wifi_scan_start(NULL, false)`。
2. `WIFI_EVENT_SCAN_DONE` 只置标志并唤醒网络任务。任务先 `esp_wifi_scan_get_ap_num`，再取最多 32 条 `esp_wifi_scan_get_ap_records`，交给合并函数，然后释放这块临时内存。
3. 合并函数在 `xhs_logic`：跳过空 SSID，同名保留更大的 RSSI，结果按 RSSI 从高到低排序，最多 12 条。每条只保留名称、RSSI、是否开放网络。
4. `GET /` 读取缓存。缓存还没准备好时，返回「正在扫描」，并用 2 秒后刷新的指令回到 `/`，不再带重新扫描参数。
5. 只有路径正好是 `/` 且查询里有 `rescan=1` 时，才请求下一次扫描。处理函数立刻返回当前缓存，不挡住套接字。扫描进行中忽略重复请求。`XHS_PROV_JOINING` 期间不扫描。
6. 通配路径上的探测请求只拿当前页面，不启动扫描。

## Form contract

字段仍是 `ssid`、`password`、`base`。新增可选的 `ssid_manual`。解码后若 `ssid_manual` 非空，用它替换 `ssid`，再走现有的 `xhs_setup_form_ok`。`xhs_setup_form_t` 不增加字段。

`XHS_SETUP_BODY_MAX` 改为 800。URL 编码的上限是 770 字节，现有的 480 不够。POST 缓冲从 481 增到 801，仍放在 httpd 栈上。不要把整页 HTML 也放上这个栈。

列表用 `name="ssid"` 的单选按钮，不设浏览器端的必填，否则只填手动名称时无法提交。手动输入放在默认收起的 `<details>` 里。页面写明：这里填了名称，就以这里为准。密码框保持可空。开放网络在该行标出「无需密码」。

名称写入 HTML 属性前转义 `&`、`<`、`"`。

## Page delivery

同一响应里先发送闪存中的页头和 `<style>`，再逐行发送网络，最后发送页尾。不要另请求 `/style.css`。不要用外链字体或图片。

四个状态共用页头、卡片和页尾。信号用 CSS 画出的四档，不放图片。点击行高至少约 44px。

配色取控制台已有的值：底 `#d5e0ea`，卡片 `#f7fafc`，文字 `#1b2836`，次要文字 `#5d6d7e`，分隔 `#d3dee8`，强调 `#d61f3c`。字体用系统字体栈，与控制台那一串回退一致，不下载字体文件。

## Compatibility

- 连接成功才保存、失败保留旧配置、后端地址可留空、热点随后关闭：行为不变。
- 文档里「页面收集家里的 Wi-Fi 名称」改为点选列表，并写明可以手动输入。中英文各一份。
- 扫描大约两秒内无线电会离开热点信道。这只在进入配网和使用者点重新扫描时发生一次，不发生在每次探测上。

## Rollback

扫描或页面生成失败时，配网仍可只用手动输入完成。不要为了列表把热点改成常开，也不要在扫描失败时拒绝提交。
